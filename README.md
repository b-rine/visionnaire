# visionnaire

An ML-powered photo app for image captioning and semantic search. Built with Triton Inference Server, Qdrant, FastAPI, and React.

## Features

- **Caption**: Upload an image and get a natural language description generated by a BLIP model running on Triton.
- **Search**: Index photos by their CLIP embeddings and search them with plain text queries.

## Stack

| Layer | Technology |
|---|---|
| Inference | Triton Inference Server (BLIP caption, CLIP encode) |
| Vector store | Qdrant |
| Backend | FastAPI |
| Frontend | React + Vite |

## Running the app

Requires Docker with NVIDIA GPU support.

```bash
docker compose up --build
```

| Service | URL |
|---|---|
| Frontend | http://localhost:3000 |
| Backend API docs | http://localhost:8080/docs |
| Qdrant dashboard | http://localhost:6333/dashboard |

## Testing

### Backend

```bash
cd backend
python -m venv .venv
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt
.venv/bin/pytest -v
```

External services (Triton, Qdrant) are mocked so tests run without Docker.

### Frontend

```bash
cd frontend
npm install
npm test
```
